# Enterprise-Homelab

## Présentation

Ce projet a pour objectif de créer un environnement virtuel reproduisant l'infrastructure d'une petite entreprise afin de développer mes compétences en administration et architecture systèmes et réseaux.

Ce laboratoire me permet de mettre en pratique dans un environnement contrôlé ces différents aspects de gestion d'infrastructure  : 
- Conception
- Déploiement
- Configuration
- Maintenance
- Veille technologique

## Objectifs

- Consulter des documentations techniques et des ressources professionnelles afin d'analyser les choix d'architecture et appliquer les bonnes pratiques
- Développer des compétences d'administration Windows Server
- Mettre en place une infrastructure Active Directory
- Configurer les rôles et services essentiels
- Installer des postes clients et utilisateurs et les répartir en différents groupes
- Créer des stratégies de groupe et les déployer
- Documenter les configurations et procédures réalisées
